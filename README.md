
# E-commerce OOP Task

Реализация базовых сущностей интернет‑магазина: Product и Category.

## Реализовано
- Класс `Product` с полями: name, description, price, quantity.
- Класс `Category` с полями: name, description, products.
- Атрибуты класса `Category.category_count` и `Category.product_count`, обновляются автоматически.
- Тесты на инициализацию и подсчёт счётчиков. Покрытие тестами >75%
