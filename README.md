
# E-commerce OOP Task

Реализация ядра интернет‑магазина: классы `Product` и `Category`, счётчики, тесты.

## Реализовано

- **Задание 1:** созданы классы `Product` и `Category` с необходимыми атрибутами.
- **Задание 2:** реализована инициализация объектов; добавлены атрибуты класса `Category.category_count` и `Category.product_count`, которые обновляются автоматически.
- **Задание 3:** написаны тесты для проверки инициализации объектов, подсчёта количества категорий и товаров. Покрытие тестами > 75 %.
- **Дополнительное задание:** реализована загрузка товаров из JSON с валидацией.

- pytest + pytest-cov (тестирование и покрытие)
- flake8, black, mypy (качество кода и типизация)

# Ecommerce Project

Проект демонстрирует базовую структуру интернет-магазина на Python с использованием объектно-ориентированного подхода.

## Функционал

В рамках текущей реализации реализованы следующие возможности:

*   **Управление товарами:** Класс `Product` хранит данные о товаре (название, описание, цена, количество).
*   **Управление категориями:** Класс `Category` группирует товары по категориям.
*   **Глобальная статистика:** Автоматическое отслеживание общего количества созданных категорий (`category_count`) и общего количества товаров во всех категориях (`product_count`) через атрибуты класса.
*   **Тестирование:** Набор unit-тестов для проверки корректности инициализации объектов и работы счетчиков.
*   **Качество кода:** Проект соответствует стандартам PEP 8 (проверено линтером flake8 с увеличенной длиной строки до 120 символов).
